This repository contains 5 Python practice exercises covering core programming and machine learning concepts.  
The exercises include Python functions, NumPy matrix operations, Pandas data analysis, Matplotlib visualization, and ML classification.  
Topics such as text processing, data manipulation, plotting, and Random Forest models are practiced.  
The goal is to improve problem-solving skills and strengthen practical coding experience step by step.  
Libraries used: NumPy, Pandas, Matplotlib, and Scikit-learn.
